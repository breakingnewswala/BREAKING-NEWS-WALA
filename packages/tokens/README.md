# @bnw/tokens — Design Tokens & Brand System

## Role & Responsibilities
Canonical source of truth for color tokens, typography stacks, spacing scales, and accessibility rules across all client surfaces.

- **Approved Brand Palette**:
  - Primary Yellow: `#FDE900` (Breaking badge, highlights, primary CTA)
  - Primary Red: `#ED1727` (Urgent alerts, breaking ribbon, live badge)
  - Primary Blue: `#344FD6` (Journalistic authority, links, correspondent badges)
- **Approved Typography**:
  - Headlines & Masthead: Rozha One
  - Body Copy & UI: Noto Sans Devanagari
  - Numerals & Slugs: Inter
- **Governing Documents**: `docs/07-Design.md`, `docs/09-Components.md`, `docs/DECISIONS.md` (`DEC-013`, `DEC-059`).
