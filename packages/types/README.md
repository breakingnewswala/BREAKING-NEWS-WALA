# @bnw/types — Shared TypeScript Contracts & Interfaces

## Role & Responsibilities
Provides unified, end-to-end type safety across Next.js frontends, authenticated workspaces, and the Express backend.

- **Standard Envelopes**: `ApiResponse<T>`, `ApiErrorResponse`, pagination schemas.
- **Enumerations**: `ArticleStatus`, `UserRole`, `DistrictCode`, `LanguageCode`.
- **Governing Decision**: `DEC-012` (TypeScript as mandatory strict language across codebases).
