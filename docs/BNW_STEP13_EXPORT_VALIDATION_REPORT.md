## 3. Discrepancies Against Prior Prepress Claims

While the generated PDF is a valid vector PDF-1.4 file, our independent inspection revealed several discrepancies against claims made in previous implementation documentation:

### 3.1 TrueType Font Embedding & Devanagari Unicode
- **Claimed**: TrueType font embedding with embedded subsetting for Devanagari typography (`Noto Sans Devanagari`, `Rozha One`).
- **Binary Reality**:
  ```text
  4 0 obj
  << /Type /Font /Subtype /Type1 /BaseFont /Helvetica >>
  endobj
  5 0 obj
  << /Type /Font /Subtype /Type1 /BaseFont /Helvetica-Bold >>
  endobj
  ```
- **Finding**: The PDF generator declares standard PostScript Type 1 `Helvetica` and `Helvetica-Bold`. It does NOT embed TrueType font programs. In PostScript streams, Devanagari text is replaced with transliterated ASCII tokens (e.g. `([VIGYAPAN / ADVERTISEMENT]) Tj`). Native Devanagari text is NOT present in the vector text stream.

### 3.2 PDF/X-1a:2001 Compliance
- **Claimed**: Commercial prepress PDF/X-1a:2001 compliance.
- **Binary Reality**:
  - Contains `/GTS_PDFXVersion (PDF/X-1a:2001)` in the `/Info` dictionary.
  - However, true ISO 15930-1 (PDF/X-1a) compliance requires:
    1. An `/OutputIntents` dictionary referencing a standardized ICC profile (e.g. Fogra39 / US Web Coated SWOP). In this file, `/OutputIntents` is **completely absent**.
    2. All fonts must be fully embedded. Here, Helvetica is referenced as an external Type 1 font.
    3. Strict prohibition of DeviceRGB color operators. In this file, **9 DeviceRGB operators (`rg`, `RG`)** are present.
- **Finding**: The output does NOT conform to true PDF/X-1a:2001 standards.

## 4. 300 DPI PNG Rasterization Inspection

- **File Signature**: Valid 8-byte PNG signature `89 50 4E 47 0D 0A 1A 0A`.
- **Image Header (`IHDR`)**:
  - Width: `3886` pixels.
  - Height: `6142` pixels.
  - Bit depth: 8, Color type: 0 (Grayscale), Compression: 0, Filter: 0, Interlace: 0.
- **Physical Dimensions Chunk (`pHYs`)**:
  - Pixels per unit X: `11811` pixels/meter.
  - Pixels per unit Y: `11811` pixels/meter.
  - Unit specifier: `1` (meter).
  - Effective DPI Calculation: $11811 \times 0.0254 = 300.00\text{ DPI}$.
- **Image Data (`IDAT`)**: Compressed with `node:zlib.deflateSync`, valid CRC32 checksums.
- **Verdict**: **100% VERIFIED AUTHENTIC 300 DPI RASTER OUTPUT**.
