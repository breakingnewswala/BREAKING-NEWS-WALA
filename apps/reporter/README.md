# @bnw/reporter — Field Reporter Web Application

## Role & Responsibilities
Mobile-first Progressive Web Application (PWA) enabling accredited field stringers, block correspondents, and citizen reporters to file breaking stories, attach GPS coordinates, upload raw photos/videos via presigned URLs, and track editorial verification status.

- **Architecture**: Authenticated Workspace PWA — Confirmed (`DEC-001`, `DEC-004`).
- **Offline Resiliency**: Local draft caching in IndexedDB for rural areas with spotty connectivity.
