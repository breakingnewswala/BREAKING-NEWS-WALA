# @bnw/web — Public News Website

## Role & Responsibilities
High-speed, SEO-optimized, server-rendered public news web portal delivering breaking alerts, district-level news feeds, live blogs, video reels, and e-paper digital editions.

- **Framework**: Next.js (App Router, React 19, Server Components) — Confirmed (`DEC-010`).
- **Styling**: Tailwind CSS v4 design tokens via `@bnw/tokens` — Confirmed (`DEC-013`).
- **Target Audience**: Citizens across 55 districts of Madhya Pradesh browsing on budget smartphones.
